# Roadmap

The roadmap sequences the AI-assisted weld-defect detection product from scaffold
to a controlled relevant-environment pilot aligned with TRL-5. Each phase has
exit gates that must be signed off by the product owner and NDT authority before
the next phase begins. Dates are indicative and depend on data authorization.

- **Phase 0 (current):** repository scaffold, synthetic smoke tests, API/UI
  dashboard and CI/CD pipeline. Deliverable: reproducible end-to-end smoke test
  on synthetic data.
- **Months 1-3:** standards review and modality inventory, customer data
  protocol, defect taxonomy and class-wise acceptance criteria. Deliverable:
  signed data agreement and approved taxonomy.
- **Months 4-7:** authorized data ingestion, expert labels with adjudication,
  baseline model and candidate model comparison, interim report. Deliverable:
  model comparison report with class-wise metrics and confidence intervals.
- **Months 8-11:** integrated workflow (ingestion, QC, inference, dashboard,
  audit trail), independent weld-group holdout test, robustness and security
  testing. Deliverable: independent test report and security sign-off.
- **Months 12-14:** controlled relevant-environment pilot, expert validation,
  final report and TRL-5 evidence review. Deliverable: pilot report, model card,
  reviewer sign-off and TRL-5 evidence package.
