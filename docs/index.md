# تشخیص عیوب جوش خطوط لوله مبتنی بر هوش مصنوعی

**شرکت گاز استان مازندران** · **مجری: شرکت پترو پالا توس** · **مجری علمی: دکتر نصرت‌علی اشرفی‌پیامن**

خوش آمدید به مستندات فنی سیستم تشخیص عیوب جوش خطوط لوله مبتنی بر هوش مصنوعی.
این سیستم یک ابزار **پشتیبانی از کارشناس** (decision-support) برای کمک به
تحلیل سریع‌تر و دقیق‌تر نتایج بازرسی جوش در شبکه انتقال و توزیع گاز است.

## نمای کلی

این محصول با هدف افزایش سرعت و دقت تشخیص عیوب جوش در خطوط لوله گازرسانی
توسعه یافته است. خروجی مدل هوش مصنوعی، **جایگزین خودکار تصمیم ایمنی نیست**؛
بلکه پیشنهانه‌ای است که باید توسط کارشناس واجد صلاحیت آزمون‌های غیرمخرب (NDT)
تأیید شود (مطابق API 1104، ASME Section V، ASME Section VIII و ASME B31.3).

## وضعیت بلوغ

این محصول بر اساس مدل **CMMI V2.0 — سطح بلوغ ۵ (Optimizing)** ساختار‌دهی شده است.
دارایی‌های فرآیندی مربوطه در پوشه [`CMMI_ML5/`](CMMI_ML5/) مستند شده‌اند و
شامل فرآیندهای سازمانی متمرکز (OPF/OPP)، نوآوری و استقرار (OID)، تحلیل علل
(CAR) و مدیریت فرآیند کمی (QPM) هستند.
