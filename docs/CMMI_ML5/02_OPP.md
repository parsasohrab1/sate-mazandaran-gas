# OPP — Organizational Process Performance (عملکرد فرآیند سازمانی)

## ۱. هدف
تعریف خط‌مبناهای کمی (baselines) برای عملکرد فرآیندهای کلیدی و استفاده از
آن‌ها برای مدیریت کمی و پیش‌بینی قابلیت اجرا.

## ۲. خط‌مبنای عملکرد فرآیند (Process Performance Baselines — PPB)

این خط‌مبناها از اجراهای گذشته استخراج می‌شوند و در `metrics/baselines.json`
نگهداری می‌شوند. در فاز اول (داده سینتتیک) به‌عنوان خط‌مبنای ابزاری ثبت
می‌شوند و پس از دسترسی به داده واقعی به‌روزرسانی می‌گردند.

| معیار | زیرپروسه | خط‌مبنای فعلی (سینتتیک) | هدف تولید (داده واقعی) | منبع داده |
|-------|----------|------------------------|------------------------|----------|
| val_f1_macro | آموزش (P-04) | ≥ ۰٫۸۰ | ≥ ۰٫۸۵ | MLflow runs |
| test_recall_crack | ارزیابی (P-05) | ≥ ۰٫۹۰ | ≥ ۰٫۹۵ | `metrics/latest/metrics.json` |
| inference_ms | خدمت‌رسانی (P-07) | ≤ ۸۰ | ≤ ۱۲۰ | `/predict` log |
| labeling_kappa | برچسب‌گذاری (P-03) | — | ≥ ۰٫۸۰ | `labeling_agreement.json` |
| imbalance_ratio | کنترل کیفیت داده (P-02) | ≤ ۲٫۵ | ≤ ۵ | `data_profile.json` |
| drift_psi | پایش (P-07) | ≤ ۰٫۱ | ≤ ۰٫۲ | drift report |

## ۳. مدل‌های عملکرد فرآیند (Process Performance Models — PPM)

رابطه علت-معلولی کمی بین عوامل فرآیند و نتایج:

**PPM-1: تأثیر حجم داده بر F1**
```
val_f1 ≈ f(n_train, imbalance_ratio, augmentation_strength)
```
به‌صورت تجربی از MLflow runs برازش می‌شود؛ برای پیش‌بینی تأثیر افزایش داده.

**PPM-2: تأثیر تأخیر کارشناس بر زمان تأیید**
```
time_to_accept ≈ inference_ms + review_latency + requeue_time
```
برای BO-3 (کاهش تأخیر).

## ۴. جمع‌آوری و تحلیل داده فرآیند

- هر اجرای آموزش/ارزیابی در MLflow ثبت می‌شود (`mlops/mlflow_config.yaml`).
- معیارها در `metrics/latest/` و به‌صورت تاریخی در `metrics/history/`.
- اسکریپت `scripts/collect_opp_metrics.py` (در PAL) به‌صورت دوره‌ای PPB را به‌روز می‌کند.

## ۵. استفاده از PPB/PPM

- **پیش‌بینی قابلیت اجرا:** آیا با حجم داده فعلی به F1 ≥ ۰٫۸۵ می‌رسیم؟
- **کنترل QPM:** انحراف از PPB هشدار می‌دهد (QPM §05).
- **تصمیم DAR:** انتخاب مدل بر اساس معیارهای کمی (DAR §07).

## ۶. به‌روزرسانی

- پس از هر OID با تأثیر بالا: به‌روزرسانی PPM.
